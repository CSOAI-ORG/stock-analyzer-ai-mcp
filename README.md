# Stock Analyzer AI MCP

Analyze stock price data with technical indicators including moving averages, RSI, and simple trend signals.

## Tools

- `calculate_sma` — Calculate simple moving average for a price series.
- `calculate_rsi` — Calculate Relative Strength Index (RSI).
- `analyze_trend` — Return trend signal based on SMA crossovers.

## Install

```bash
pip install -e .
```

## Run

```bash
python -m stock-analyzer-ai-mcp.server
```
